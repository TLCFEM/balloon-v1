\section{A Flexible Isotropic Hardening}
\subsection{History of Load Reversals}
In conventional plasticity models, local reversals cannot be easily detected.
A common criterion for detecting reversals is the double contraction $\beeta:\dot{\beeta}$.
For example, in the multi-surface theory \citep{Semenov2022}, the exact criterion is used to identify the initiation of a load reversal, which further controls the activation of a new surface.

The normal yield ratio $z$ effectively represents the current `loading level' at any given moment.
By definition, this loading level is normalised between \num{0} and \num{1} thus does not depend on the current size of the yield surface: when it increases, the subloading surface expands, indicating a loading process; when it decreases, the subloading surface contracts, indicating an unloading process.
Thus, load reversals can be detected with ease by checking whether $z$ ever decreases within the given (sub-)step.

For a material (point) that has experienced up to $N$ load reversals, let the normal yield ratio at each load reversal be denoted as $z_r^j$ with $j=1,2,3,\cdots,N$ standing for the $j$-th reversal.
The initial value, if required, can be set to zero: $z_r^0=0$.
We use $z_r$ to denote some measure of the entirety of $z_r^j$, thus,
\begin{gather}
    \boxed{z_r=Z\left(\left\{z_r^j\right\}_{j=0}^N\right)=Z\left(z_r^0,z_r^1,z_r^2,\cdots,z_r^N\right).}
\end{gather}
In the above, $Z\left(\cdot\right)$ is a function that maps the collection $\left\{z_r^j\right\}_{j=0}^N$ to a single scalar $z_r$.
Depending on the specific choice of function $Z$, $z_r$ embodies different memory effects.
For example, $z_r$ can take the maximum/minimum value of the most recent $M$ values.
When $M=1$, $z_r$ is the most recent value $z_r^N$.
When $M\geqslant{}N$, $z_r$ is simply the maximum/minimum value of all $z_r^j$.
\subsection{Additive Decomposition of Plastic Strain}
It is possible to split the plastic strain $\bvarepsilon^p$ into at least two parts,
\begin{gather}\label{eq:split_ep}
    \bvarepsilon^p=\bvarepsilon^p_m+\bvarepsilon^p_c+\cdots,
\end{gather}
with $\bvarepsilon^p_m$ denoting the `monotonic' part and $\bvarepsilon^p_c$ denoting the `cyclic' part.
The rationale behind this split is straightforward: the accumulated plastic strain $q$ defined in \eqsref{eq:q_original} only tracks the total amount of plastic deformation, although it is non-decreasing, there is no way to infer further details of the corresponding loading process.
The split \eqsref{eq:split_ep} allows one to distinguish between the plastic strain accumulated during monotonic loading (according to an appropriate definition of `monotonic') and that accumulated during load reversals.
This distinction makes it possible to account for various microstructural effects, such as the rearrangement/annihilation of dislocations.
It is reasonable to assume that the plastic strain increment $\dot{\bvarepsilon}^p$ within a given (sub-)step would be distributed between two parts according to some rule, which may depend on the current loading level $z$, and/or its history $z_r$.
Without loss of generality, one can thus define
\begin{gather}\label{eq:split_q_definition}
    \dot{\bvarepsilon}^p_m=K_m\dot{\bvarepsilon}^p,\qquad\dot{\bvarepsilon}^p_c=K_c\dot{\bvarepsilon}^p,
\end{gather}
where $K_m=K_m\left(z,z_r\right)$ and $K_c=K_c\left(z,z_r\right)$ are functions of $z$ and $z_r$ (or equivalently, $\left\{z_r^j\right\}_{j=0}^N$) that yield ratios between zero and unity.
It is possible to further impose the constraint $K_m+K_c=1$ such that there are exactly two components $\bvarepsilon^p=\bvarepsilon^p_m+\bvarepsilon^p_c$, however, this is not strictly necessary.
A similar split can be applied to $q$ such that
\begin{gather}\label{eq:split_q}
\boxed{\dot{q}_m=K_m\dot{q},\qquad\dot{q}_c=K_c\dot{q}.}
\end{gather}

It is possible to propose a more sophisticated definition of $K_m$ that may further account for other history variables, such as plastic strain.
We are refrained from doing so in this work to keep the formulation simple.
\subsection{Proposed Isotropic Hardening}
With \eqsref{eq:split_q}, the isotropic bound $F$ can be defined as a function of both $q_m$ and $q_c$ instead of $q$.
Assuming an additive decomposition, it can be expressed as
\begin{gather}\label{eq:f_revised}
    F=F_m+F_c.
\end{gather}
In the following, we elaborate the two components $F_m$ and $F_c$ and their effects on isotropic hardening respectively.
\subsubsection{Work/Isotropic Hardening Stagnation}
Noting that there is deterministic mapping between $\Delta{}z$ and $\Delta{}q$ (see discussions around \eqsref{eq:int_z}), those aforementioned strain space formulations for isotropic hardening stagnation can be equivalently reformulated in the $z$ space, thus the stress space.
We assume
\begin{gather}\label{eq:isotropic_stagnation}
    F_m=F_m\left(q_m\right)
\end{gather}
is a function of $q_m$ solely.
By choosing a proper $K_m$, for example, $K_m=0$ for $0\leqslant{}z\leqslant{}z_r$, it is possible to fully deactivate the evolution of $q_m$, thus $F_m$, during cyclic loading phase.

This type of stagnation is similar to the approach proposed by \citet{Ucak2011,Ucak2012}, who used a certain set of criteria based on the same memory surface \citep{Ohno1982} to distinguish between two distinct regions/phases: the plateau region where isotropic hardening stagnates, and the hardening region where isotropic hardening evolves normally.
A recent application of this idea can be found in the work by \citet{Hu2018}.
Unlike existing formulations, the proposed approach \eqsref{eq:isotropic_stagnation} requires no additional history variables for a secondary surface (whether defined in stress or strain space).
Similar information has already been inherently embedded in $z$.
Furthermore, because $z$ is a scalar, it avoids tensor bookkeeping and yields a simpler, more efficient implementation.
Finally, because $K_m$ is a continuous function, when $z$ gradually increases, it can be gradually (re-)activated from a partially or fully deactivated state.
\subsubsection{Cyclic Hardening/Softening}
The cyclic hardening/softening is controlled by $F_c$, which is assumed to be governed by the following evolution rule,
\begin{gather}\label{eq:fc}
\boxed{\dot{F_c}=b_f\left(H_c-F_c\right)\dot{q}_c\qquad\text{with}\qquad{}H_c=H_c\left(q_m\right).}
\end{gather}
In the above, $b_f$ is a material parameter that controls the rate of saturation, and $H_c$ is the saturation value that may depend on $q_m$.
It is possible to associate $H_c$ with $F_m$ such that the former is a fraction of the latter.
With the evolution of $q_c$, $F_c$ would gradually saturate to $H_c$.
Meanwhile, since $H_c=H_c\left(q_m\right)$ depends on $q_m$, it would also evolve during monotonic loading phases.
\eqsref{eq:fc} thus allows multi-stage saturation that allows cyclic hardening/softening under various loading histories.
This differs from other models in the literature \citep[e.g.,][]{Ohno1982,Zheng2026} in which similar saturation can only occur once.
\subsubsection{Other Relavent Changes}
With \eqsref{eq:f_revised}, the size of the subloading surface (isotropic hardening) is bounded by $F_m+H_c$ which is governed by $q_m$ solely.
Stable hysteresis loops would eventually saturate $F$ to this value via the accumulation of $q_c$.
In principle, a similar definition can be applied to bounds $H_\alpha$ and $H_d$.
However, there is no strong experimental evidence indicating that these bounds exhibit hardening or softening behaviour.
To avoid unnecessary complexity, they are defined solely as functions of $q_m$, i.e., $H_d=H_d\left(q_m\right)$ and $H_\alpha=H_\alpha\left(q_m\right)$.
\subsection{Objective Transition}\label{sec:obj_trans}
As shown in \eqsref{eq:int_z}, for a given interval of $z$, the corresponding change in $q$ is always constant, regardless of the specific form of $U(z)$ --- as long as it is given.
However, $z$ only measures the relative loading level.
As a result, the response curve becomes steeper when the yield stress is larger, and less so when it is smaller.
To make this transition more objective and less dependent on material parameters, we propose the following enhancement.
\begin{gather}\label{eq:z_evolution_revised}
    \boxed{\dot{z}=\dfrac{U}{F}\dot{q}.}
\end{gather}

Furthermore, in earlier models \citep{Chang2025,Hashiguchi2024}, the function $U$ does not consider loading history.
It is further extended in this work to account for loading history by introducing the dependence on $q_m$.
Thus, $U=U\left(q_m,z\right)$.
A typical choice can be
\begin{gather}
    U\left(q_m,z\right)=-u\ln{z}
\end{gather}
with $u=u\left(q_m\right)$ being a varying parameter that graudally decreases with $q_m$.
Or, following the suggestion by \citet{Chang2025}, a power function can be used,
\begin{gather}
    U\left(q_m,z\right)=u\left(z^{-n}-1\right)\qquad\text{for}\qquad0<n\leqslant1,
\end{gather}
again, with $u=u\left(q_m\right)$.
\subsection{Choice of $K_m$ and $K_c$}
As explained earlier, the introduction of $z_r$ allows one to identify two distinct loading phases: monotonic loading when $z$ increases from $z_r$ to \num{1}, and cyclic loading when $z$ increases from \num{0} to $z_r$.
The split functions $K_m$ and $K_c$ shall meet the following requirements.
\begin{enumerate}
    \item For $0\leqslant{}z<z_r$, $\dot{q}$ mostly distributes to $\dot{q}_c$.
    \item For $z_r\leqslant{}z\leqslant{}1$, $\dot{q}$ mostly distributes to $\dot{q}_m$.
    \item The amount of $\dot{q}_m$ accumulated during cyclic loading phase shall be inversely proportional to $z_r$.
\end{enumerate}
To fulfil these, the following expression is chosen for $K_m$ in this work.
\begin{gather}\label{eq:km}
    K_m=\begin{cases}
        0,                                          & 0\leqslant{}z<z_r,           \\
        1-\exp{\dfrac{z-z_r}{k_r\left(z-1\right)}}, & z_r\leqslant{}z\leqslant{}1,
    \end{cases}
\end{gather}
in which $k_r$ is a material parameter that controls the transition.
\eqsref{eq:km} provides a smooth transition of $K_m$ from zero at $z=z_r$ to unity at $z=1$.
The function is illustrated in \figref{fig:km}.

It is assumed that $K_c=1-K_m$.

For specific applications, minor changes, for example, accounting for extra constants $\sqrt{\dfrac{2}{3}}$ in von Mises models \citep[see][]{Chang2025}, may be made.

For scalar bounds $H_\alpha=H_\alpha(q_m)$, $H_d=H_d(q_m)$,  $H_c=H_c(q_m)$ and $F_m=F_m(q_m)$, any suitable univariate functions can be chosen, so we keep the corresponding expressions general.
Popular options may include a liner component, an exponential component that saturates, and/or a power term.

A careful examination shows the boundary between subloading surface theory and conventional plasticity is blurred.
In specific, the following can be observed.
\begin{enumerate}
    \item The term $zF$ controls the effective size of the yield surface: during loading $zF$ grows from $0$ to $F$, so there is no initial elastic domain.
          It is possible to define a similar loading behaviour in conventional plasticity by using an isotropic hardening function that starts from zero.
    \item During unloading, the subloading surface contracts so the current stress point remains on the surface.
          This can also be achieved in conventional plasticity by simply adjusting isotropic hardening.
    \item The term $\left(1-z\right)H_d\bd$ acts as an additional, generalised back stress contribution, complementing the conventional $H_\alpha\balpha$ term.
\end{enumerate}
Without introducing any additional (memory) surfaces, \tabref{tab:summary} shows that the subloading surface theory can be deemed as a generalisation of conventional plasticity, and it is effectively a single surface theory.
The proposed model mimics a balloon, expanding during loading and contracting during unloading.
It is thus denoted as the \texttt{balloon} model.
